# Скрипты анализа трафика по оптическому потоку

Все скрипты используют общий модуль очистки потока `flow_filters.py`. Требуется `pip install opencv-python numpy`. Русские подписи на видео дополнительно требуют `pillow`; без него подписи будут латиницей.

## Что запускать

| Скрипт | Что делает | Выход |
|---|---|---|
| `flow_canvas.py` | Основная визуализация: видео, графики, холсты дивергенции и ротора | 6 видео и CSV на каждое входное видео (см. ниже) |
| `flow_heatmap_with_decay.py` | Ваш скрипт: heatmap и стрелки; в углу добавлена панель с дивергенцией, ротором и скоростью | 11 видео и `flow_stats.csv` |
| `run_dataset.py` | Пакетный прогон обоих скриптов по папкам с видео. Параллельно, с пониженным приоритетом, продолжает с места остановки | структура папок ниже |
| `summarize_results.py` | Сводная таблица по результатам прогона | `summary_videos.csv`, `summary_classes.csv`, `summary.md` |
| `divergence_curl.py` | Отдельно дивергенция и ротор (простой вариант) | `divergence.mp4`, `curl.mp4`, `div_curl.csv` |
| `Heatmap.py`, `opticalflowwithdecay.py` | Ваши первые скрипты, исправленные (очистка шума, камера, маска дороги) | видео рядом со скриптом |

### Модули

| Модуль | Назначение |
|---|---|
| `flow_filters.py` | `FlowCleaner` — очистка потока; `SceneGuard` — монтажные склейки и негодные кадры |
| `divergence_curl.py` | `DivCurl` — дивергенция и ротор по клеткам, в 1/с |
| `flow_stats.py` | `SpeedMeter` — средняя скорость потока и её падение |
| `flow_stopped.py` | `StoppedDetector` — стоящие машины (застой); `merge_boxes` — слияние пересекающихся рамок по IoU |
| `flow_stats.py` (`IncidentRule`) | правило «ДТП?»: стоят ≥ 20 с и за последние 40 с скорость потока падала ≥ 35% |

## Примеры

```bash
# одно видео
python flow_canvas.py --video ../traffic_flow_dataset/5_avariya/b2D9m3upSZQ.mp4 --out_dir out
python flow_heatmap_with_decay.py --video ../traffic_flow_dataset/5_avariya/b2D9m3upSZQ.mp4 --max_width 640 --out_dir out_fh

# весь датасет (повторный запуск той же командой продолжит с места остановки)
python run_dataset.py --inputs ../traffic_flow_dataset ../newVideos --out_root "../../Результаты прогона" --jobs 6
python summarize_results.py --root "../../Результаты прогона"

# только таблицы, без видео (быстро)
python run_dataset.py --inputs <папка> --out_root <куда> --scripts canvas --canvas_outputs none
```

## Структура результатов

```
<out_root>/
  canvas/
    combined/      все 4 части вместе: видео+стрелки | графики / дивергенция | ротор
    video_arrows/  видео + стрелки поля + оранжевые рамки стоящих машин
    divergence/    белый холст: дивергенция
    curl/          белый холст: ротор
    graphs/        графики: скорость V(t), стоящие машины %, div и |rot|
    corner/        видео + дивергенция, ротор и скорость в правом верхнем углу
    stats/         CSV по кадрам
  flow_heatmap/<датасет>/<класс>/<видео>/   11 видео flow_heatmap_with_decay.py + flow_stats.csv
  run_log.csv      журнал прогона
```

Внутри каждой папки повторяется структура `<датасет>/<класс>/<видео>`.

## Колонки CSV (по кадрам)

| Колонка | Смысл |
|---|---|
| `valid`, `cut` | кадр годен / на кадре монтажная склейка (тогда всё сбрасывается) |
| `speed_px_s` | средняя скорость потока V за 1 с, px/с исходного видео (медиана) |
| `speed_base_px_s` | обычная скорость: медиана первых 3 с, дальше среднее за ~10 с |
| `drop` | падение скорости 1 − V/V_base (0 — как обычно, 1 — встали; пусто — нет движения на пустой дороге) |
| `moving_area` | доля дороги в движении |
| `div_*_per_s`, `rot_*_per_s` | дивергенция и ротор по активным клеткам, 1/с |
| `stopped_frac`, `occupied`, `stopped_max_age_s` | доля дороги со стоящими машинами, флаг «дорога занята», сколько стоит самая давняя |
| `incident` | 1 — правило «ДТП?» сработало на этом кадре |

## Что изменено и почему (кратко, с замерами)

- **Пороги очистки** `deadband_rel` 0.08 → 0.02, `deadband_k` 3 → 2. Медленные машины (0.05–0.2 px/кадр) теперь ловятся: у места ДТП 14% → 61%, в пробках 41% → 61%. Ложное движение на 10 пустых дорогах не выросло: 0.53% → 0.54%.
- **Монтажные склейки** (`SceneGuard`). Новостная заставка давала скачок скорости до 2000 px/с и портила все средние. Теперь на склейке состояние сбрасывается.
- **Вспышка — не склейка.** Если весь кадр разом стал темнее или светлее (мерцание, автоэкспозиция, свет фар при ударе), а картинка та же, это не склейка. Такой кадр пропускается, но ничего не сбрасывается. На view3 одиночный тёмный кадр на 36.72 с раньше считался склейкой: сброс стирал фургон, стоявший после ДТП, и правило «ДТП?» аварию пропускало. Теперь оно срабатывает на 49 с, рамка на фургоне. По всем 435 видео склейки изменились только на трёх: view3, other_crash_68 (вспышка при ударе) и b2D9 (лишние «склейки» внутри новостной заставки). Новых склеек нигде не появилось.
- **Скорость потока** считается медианой (а не средним), базовая скорость — после прогрева 3 с. Пустая дорога больше не показывается как «падение 100%».
- **Стоящие машины** (`StoppedDetector`): фон с медленным обучением минус движение, только на дороге. На b2D9 после ДТП доля стоящих 0 → 3.5–4.3% дороги и держится до конца. На нормальных видео и пустых дорогах около 0.
- **Ротор аварию не показывает, и это физика, а не ошибка.** После ДТП машины стоят: потока нет, значит нет и вращения. Ни один вариант ротора (среднее, p95, максимум, аномалия клетки, сдвиг) не отделил аварию от нормальных видео. Ротор полезен как картинка манёвров (объезд, перестроения). Признаки аварии на потоке — падение скорости и появление стоящих машин.
- **Маска дороги** пропускает медленные полосы: граница активности 5% → 1% от самой быстрой клетки. На заторе 3_/471 правые полосы в маске: 27% → 94% площади. Ложное движение на пустых дорогах не выросло.
- **Длина стрелок пропорциональна корню из скорости.** Так ползущая полоса видна рядом с быстрой; направление стрелок точное.
- **Рамки стоящих машин сливаются по IoU**: пересекающиеся и касающиеся рамки (запас ~10 px при ширине 640) объединяются в одну, время стояния — по самой давней.
- **Правило «ДТП?»** (`IncidentRule`): рамка становится красной с подписью «ДТП? стоят N с», в угловой панели и на графиках появляется «ДТП?». Условие: что-то стоит ≥ 20 с И за последние 40 с скорость потока падала ≥ 35%. На b2D9 срабатывает на 38 с (через 19 с после удара). Ограничение: долгая очередь на красный свет тоже может дать «ДТП?».
- **Дивергенция в пикселях кадра зависит от перспективы.** Уезжающая от камеры полоса «сходится» даже при свободном движении. Поэтому затор — это изменение div в клетке относительно её обычного значения, а не сам знак.

## Ограничения

- Стоящую с первого кадра очередь детектор не видит: она попадает в фон.
- Скорость в px/с сравнима во времени внутри одного видео, но не между камерами (перспектива).
- Снегопад у самой камеры и ночная съёмка с дрона дают ложное движение 1.5–3.7% кадра.
